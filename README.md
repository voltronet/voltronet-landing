## 🌐 Overview

**VOLTRONET** is a high-availability cloud infrastructure and DevOps engineering platform specialized in building scalable cloud-native architectures, automated CI/CD pipelines, and zero-downtime deployment workflows. 

This repository houses the source code for the official enterprise landing page and client portal, built with modern frontend paradigms, responsive glassmorphic UI elements, and a lightweight bilingual architecture (Romanian / English).

---

## 🛠️ Technology Stack

* **Frontend Design:** Tailwind CSS (JIT, Custom Dark Glassmorphism Theme)
* **Interactivity & i18n:** Vanilla JavaScript (Dynamic DOM manipulation & state-based multi-language switcher)
* **Icons & Typography:** FontAwesome 6, Google Fonts (`Inter`, `Fira Code`)
* **Containerization:** Nginx web server running within an optimized Docker container
* **Infrastructure & Automation:** Terraform, Ansible, GitHub Actions, Docker, Kubernetes (Kind)
